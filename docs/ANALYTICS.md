# PLOT Analytics & Product Metrics

## 1. Tracked Events
- `app_opened`, `home_viewed`, `story_card_viewed`
- `story_started`, `episode_started`, `choice_presented`, `choice_selected`
- `episode_completed`, `story_completed`, `ending_unlocked`
- `paywall_viewed`, `purchase_started`, `purchase_completed`, `subscription_started`

## 2. Core Funnel & North Star
- **North Star Metric**: **Weekly Completed Story Journeys**
- **Conversion Funnel**:
  `Home -> Story Detail -> Episode 1 Complete -> Episode 3 Complete -> Story Complete -> Ending Unlocked -> Replay / Second Story -> PLOT+`
